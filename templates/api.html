JSON API

The API lets other programs read and manage student records without the web pages. Send the token from the SGP_API_TOKEN setting in the X-API-Token header on every request.

Method Path What it does
GET /api/students List every student with marks, total, percentage, grade and result.
POST /api/students Create a student from a JSON body: {"name": "...", "marks": [...]}.
GET /api/students/<reg_no> Fetch one student together with the extra profile fields.
DELETE /api/students/<reg_no> Permanently delete one student.
GET /api/openapi.json Machine-readable OpenAPI description of the endpoints.

Example

curl -H "X-API-Token: $SGP_API_TOKEN" http://127.0.0.1:5000/api/students

The API is exempt from the browser CSRF check because it is meant for server-to-server calls, so keep the token secret and change it in production.
